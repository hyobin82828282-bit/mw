재고실사 콘솔

WMS에서 내려받은 재고 원본 파일을 올리면 냉동 / 상온·냉장 실사표를 자동으로 나눠드립니다. 현장 카운트 후 실수량을 채운 파일을 다시 올리면 차이수량·실사요약·폐기대상까지 한 번에 정리합니다. 처리는 이 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다.

예시 미리보기 — 실사표(냉동) 시트 구조
품목코드품목명분류1분류2분류3유통기한가용수량실수량차이수량
2019XXXXXXXX[M냉동] 예시품목A 500g705 평치——2027-02-25642640-2
2019XXXXXXXX[M냉동] 예시품목B 300g705 평치——2027-05-111491490
2019XXXXXXXX[M냉동세트] 예시세트C701 랙A02—2026-11-309194+3
📌

제외품목 고정

제외품목 시트가 담긴 파일을 한 번만 올려두면 이 브라우저에 저장되어, 앞으로 올리는 원본 파일에 제외품목 탭이 없어도 자동으로 적용됩니다. 원본 파일에 제외품목 탭이 있으면 두 목록을 합쳐서 사용합니다. 이 브라우저에만 저장되며 다른 기기·다른 사람과는 공유되지 않습니다.

현재 고정된 제외품목이 없습니다.
1

실사표 + 폐기대상 만들기

WMS 원본 파일(Sheet1 포함, .xlsm/.xlsx)을 올리면 품목명 키워드와 재고상태(가용/불용(대기))로 걸러 냉동 · 상온,냉장 실사표를 만들고 분류1→2→3 순으로 정렬합니다. 이상재고(불량/임박/분실/파손/불용)는 같은 자리에서 폐기대상 시트로도 뽑아 드립니다. 단, 불용(임박)이라도 유통기한이 오늘 기준 D+3 이상이면 재고로 두어 실사표에 넣고 유통기한 칸을 노랗게 표시합니다. 제외품목 시트도 결과 파일에 함께 만들어지며, 품목코드별 품목명·가용수량을 원본 Sheet1에서 찾아 자동으로 채워 넣습니다.

실수량(I열)을 채운 뒤 아래 2단계에 다시 올려주세요. 두 시트 모두 I열이 비어 있는 상태로 생성됩니다.
2

차이·요약·폐기대상 생성

실수량을 채운 파일을 올리면 차이수량(K열)을 다시 계산하고, 실사요약(차이수량≠0), 전체실사요약(품목별 합계), 폐기대상(불량/임박/분실/파손/불용) 시트를 최신 상태로 다시 만들어 하나의 결과 파일로 돌려드립니다. 유통기한이 오늘 기준 D+3 이상인 불용(임박)은 폐기대상에서 빠집니다.

3

WMS 업로드용 재고조정 파일

폐기대상 시트와 같은 기준으로 이상재고(불량/임박/분실/파손/불용, 불용(대기) 제외)만 뽑아 조정수량 0으로 채운 WMS 재고조정 양식(stock_new_v2, 4행부터 · 모든 값 텍스트)을 만듭니다. 재고상태는 코드로 변환됩니다 (임박=2 · 불량=3 · 분실=4 · 파손=5 · 기타=6). 유통기한이 오늘 기준 D+3 이상인 불용(임박)은 재고로 두므로 조정하지 않습니다.

참고 — Lot No. 열은 헤더가 실제로 "Lot No."인 컬럼 값을 사용합니다.
4

조정수량 → WMS 입고 · 차감 업로드

전체실사요약 시트의 조정수량 열에 수량을 적은 파일을 올리세요. +수량은 실사요약에서 같은 품목의 ▲입고필요 셀을, −수량은 ▼차감필요 셀을 찾아 유통기한이 빠른 셀부터 그 셀의 차이수량만큼 채워 나눕니다.
· 입고: put_insert 양식(.xlsx, 모든 값 텍스트, 재고상태 가용)
· 차감: WMS 재고조정 양식(stock_new_v2, .xlsx, 4행부터 · 모든 값 텍스트) (조정수량 = 가용수량 − 차감수량, 즉 남길 수량 · 가용=0, 불용(대기)=1)

참고 — 로케이션2·3은 두 자리 텍스트(예: 1 → "01")로 맞춥니다. Lot/Batch는 파일에 Sheet1이 있으면 같은 품목·로케이션·유통기한 행에서 가져옵니다.
